# SUKUNA RSBoost v2 — Premium Minimal Dashboard

Premium/minimal dashboard foundation with a monochrome black/graphite palette and subtle accenting.

## Run
npm install
npm run dev

## Included UI
- Overview / Command Center
- Domain I — Video Fetch
- Domain II — Shrine Studio
- Domain III — YouTube Publishing
- Domain IV — Upload Queue (50 capacity)
- Domain V — Sukuna Vault

Backend, FFmpeg processing, storage, OAuth and YouTube API are intentionally not connected yet.
